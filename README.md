# Music Muse 2.2

מקום בעברית לגלות מוזיקה, לצפות בסרטונים ולבנות ספרייה אישית, בעיצוב הכהה, הוורוד, הסגול והתכלת של Music Muse.

האתר מגיע מוכן לשימוש: **33 סרטוני YouTube ושני סרטוני TikTok נטענים אוטומטית גם למבקר חדש**. אין צורך לחבר חשבון, להזין מפתח או להדביק קישור כדי להתחיל לצפות. המבקר בוחר סרטון ולוחץ ניגון. בחלק מהדפדפנים נדרשת לחיצת ניגון נוספת בתוך הנגן הרשמי.

שרת האתר מעדכן את אוסף YouTube מהעדכונים הציבוריים של ערוצי ישי ריבו ובני פרידמן. התוצאות נשמרות עד 15 דקות בכל מופע שרת; לאחר כשל עדכון נעשה ניסיון נוסף אחרי דקה. האוסף המובנה זמין מיד בממשק וגם כאשר הערוצים או שרת ה־API אינם משיבים. משך הסרטון ונתוני צפיות אינם מומצאים כאשר אינם זמינים.

TikTok נפתח עם **בחירת האתר** ועם סרטונים שהמבקר בחר להוסיף. זה אינו פיד For You אישי ואינו חיפוש חופשי בכל TikTok. הנגן, הגלילה, הלב והשמירה נשארו באותה מעטפת; נגן יחיד פעיל בכל רגע. הוספת קישור אישי נשארת אפשרות נוספת בלבד.

## פריסה ב־Vercel

1. מייבאים את מאגר GitHub. הקבצים `package.json` ו־`vercel.json` חייבים להיות בשורש המאגר.
2. בוחרים **Framework Preset: Other**, משאירים **Root Directory** ריק או `.`, ולוחצים **Deploy**. התצורה מגדירה `npm run build` ותיקיית פלט `public`.
3. פותחים את האתר: הסרטונים כבר מוצגים. אין צורך בהגדרת משתני סביבה כדי להשתמש באוסף YouTube או TikTok.
4. לחיפוש מורחב בכל YouTube בלבד, בעל האתר יכול להוסיף ב־Vercel את `YOUTUBE_API_KEY` ולבצע **Redeploy**. לאחר מכן כל המבקרים נהנים מחיפוש מורחב בלי להזין מפתח בעצמם.

אין להגדיר `public` בתור Root Directory: קוד ה־API נמצא בשורש הפרויקט. פריסה בפועל בחשבון Vercel נעשית לאחר חיבור המאגר בידי בעל האתר.

### הגדרות אופציונליות לבעל האתר

| משתנה | שימוש |
| --- | --- |
| `YOUTUBE_API_KEY` | חיפוש חופשי דרך YouTube Data API v3. אינו דרוש לאוסף הסרטונים או לניגון. נשאר בשרת ואינו נשלח למבקר. |
| `APP_ACCESS_TOKEN` | קוד משותף להגנת נתיבי ה־API בפריסה פרטית. אינו מערכת חשבונות ואינו מגן על קובצי הממשק הציבוריים. |
| `PORT` | פורט מקומי; ברירת המחדל 4173. |

למפתח חיפוש מורחב מפעילים YouTube Data API v3 בפרויקט Google Cloud ומגבילים את המפתח לשירות זה. החיפוש יוצא מהשרת; יש לבחור הגבלות שמתאימות לשרת. מכסת החיפוש נקבעת בחשבון Google. ממשק המבקרים אינו מבקש מפתח אישי.

## מה זמין ללא הגדרה

| מקור | גילוי וחיפוש | ניגון |
| --- | --- | --- |
| YouTube — בחירת האתר וערוצי האתר | נטען בכניסה; חיפוש בשמות ובתגיות שבאוסף, קטגוריות וטעינת עמוד נוסף | נגן YouTube הרשמי |
| YouTube — חיפוש מורחב | זמין אוטומטית למבקרים אם בעל האתר הגדיר מפתח שרת | אותו נגן רשמי |
| TikTok — בחירת האתר | רצף מוכן, בגלילה ובחצים, ללא קישור מצד המבקר | נגן TikTok רשמי יחיד לסרטון הפעיל |
| קטלוג iTunes | חיפוש בעברית ובאנגלית, ללא מפתח | קטע היכרות עם קישור לשיר המלא בחנות |
| קבצים מהמכשיר | הוספת שמע או וידאו, סינון וחיפוש מקומיים | ניגון מקומי בפורמטים הנתמכים בדפדפן |
| קישורים אישיים | הוספת YouTube או TikTok כאפשרות נוספת, כולל קישורים קצרים של TikTok | בנגנים הרשמיים, כשההטמעה מותרת |

חיפוש ללא מפתח מסנן את אוסף האתר וערוציו, ואינו מוצג כחיפוש בכל YouTube. סרטונים שהוסרו, הוגבלו להטמעה או לאזור, או חסומים ברשת, עשויים שלא להתנגן. אין כאן עקיפה של דרישות הספק או של סינון רשת.

## שימוש קצר

- בכניסה בוחרים סרטון מהאוסף שכבר נטען. אפשר ללחוץ על הצעות האמנים או לחפש באוסף.
- בלשונית **TikTok** הסרטונים מוכנים בגלילה אנכית. החצים ומקשי מעלה/מטה עוברים בין הסרטונים. אפשר להפעיל צליל ואת הפקדים המקוריים.
- הלב מוסיף לאהובים ו״שמירה״ מוסיפה לספרייה. האוסף המובנה אינו מוסיף פריטים למועדפים בלי בחירה של המבקר.
- מתפריט הסרטון אפשר להוסיף לפלייליסט, לעקוב אחרי אמן, לשתף או להסתיר. תור ניגון מיועד ל־YouTube ולקבצים אישיים; קטעי iTunes נשארים קטעי היכרות נפרדים.
- קבצים מהמכשיר נשמרים ב־IndexedDB ואינם מועלים לשרת. עד 200 קבצים בהוספה ועד 300MB לקובץ, בכפוף לאחסון הזמין.
- גיבוי JSON בהגדרות כולל העדפות ומידע, ללא מדיה או מפתחות. ייבוא ממזג את הספרייה הקיימת.
- חלונית מוקד המערכות מופיעה לכל היותר פעם בחמש דקות בדפדפן, ומאפשרת סגירה אחרי חמש שניות. יש בה קישורים למתמחים טופ, לבינה טופ ולמייל.

## הפעלה מקומית

נדרשת Node.js 24. ב־PowerShell בתיקיית הפרויקט מריצים:

```powershell
npm start
```

פותחים `http://localhost:4173`. אין חבילות npm בזמן ריצה ואין צורך במסד נתונים. אפשר להעתיק `.env.example` ל־`.env` להגדרות אופציונליות; אין להעלות `.env` למאגר. אין לפתוח את `index.html` כקובץ מקומי: מודולי JavaScript, ה־API והנגן הרשמי צריכים שרת HTTP או HTTPS.

## נתונים ופרטיות

הספרייה וההעדפות נשמרות ב־localStorage; מדיה אישית נשמרת ב־IndexedDB. אין סנכרון בין מכשירים או מערכת חשבונות. מחיקת נתוני האתר עלולה למחוק נתונים מקומיים. מעבר לדומיין אחר יוצר אחסון נפרד; אפשר להעביר מידע בעזרת גיבוי.

בקשות לחיפוש ולרענון ערוצים עוברות דרך שרת האתר אל הספק הרלוונטי. עטיפות ונגנים נטענים מהספקים הרשמיים. Service Worker שומר מעטפת ממשק בלבד, כולל האוסף המובנה; אינו שומר תשובות API, קטעי iTunes או סרטונים. ניגון מדיה חיצונית דורש אינטרנט.

## בדיקות

```powershell
npm test
npm run build
```

44 בדיקות אוטומטיות מכסות נתונים, ייבוא, גיבוי, תור, כתובות, נתיבי API, TikTok וחלונית היוצר. בדיקות הגילוי מכסות מבקר חדש, שדרוג ללא מחיקת ספרייה, חיפוש בעברית, קטגוריות, דפדוף, עדכוני Atom, הגבלת מקורות, מטמון ועמידה בכשל ספק. הבדיקות האוטומטיות אינן דורשות מפתח או אינטרנט.

בבדיקה חיה התקבלו 15 פריטים מכל אחד משני ערוצי YouTube בעת הכנת האוסף. בדיקת רענון נפרדת הצליחה לעדכן ערוץ אחד בתוך מגבלת הזמן, והאוסף נשאר מלא גם כשהערוץ השני לא השיב בזמן. תרחישי בדיקת דפדפן ופריסה: [docs/TESTING.he.md](docs/TESTING.he.md). רשימת התכונות: [docs/FEATURES.he.md](docs/FEATURES.he.md).

## מבנה ומקורות

- `public/discovery.js` — אוסף הסרטונים, הכנת מבקר חדש וחיפוש מקומי.
- `lib/discovery.js` — קריאת ערוצים ציבוריים, אימות מזהים ומטמון.
- `public/app.js` ו־`public/shorts.js` — ממשק, ספרייה ונגנים.
- `lib/providers.js` ו־`api/index.js` — ספקים ונתיבי שרת ל־Vercel.
- `public/creator-promo.js` — ספירה לאחור ותדירות חלונית היוצר.
- [YouTube — Atom channel feeds](https://developers.google.com/youtube/data/guides/push_notifications)
- [YouTube — Data API requirements](https://developers.google.com/youtube/data/reference/rest)
- [TikTok — official embedded player](https://developers.tiktok.com/docs/en/embed-player)

הגבלת הבקשות היא לכל מופע שרת חם. אם מפעילים חיפוש מורחב באתר ציבורי, אפשר להגדיר מגבלות נוספות בחשבון Google וב־Vercel.
