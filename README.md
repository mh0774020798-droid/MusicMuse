# Music Muse 2.0

מקום בעברית לגלות מוזיקה, לשמור שירים וביצועים ולנגן ספרייה אישית. העיצוב שומר על הרקע הכהה, הוורוד, הסגול והתכלת של הגרסה המקורית.

הפרויקט כולל ממשק, API ל־Vercel, ספרייה מקומית, בדיקות והוראות הפעלה. אין תלויות npm בזמן ריצה ואין צורך במסד נתונים.

## פריסה ב־Vercel

1. מעלים את **תוכן התיקייה** למאגר GitHub. הקבצים `package.json` ו־`vercel.json` צריכים להיות בשורש המאגר, לצד התיקיות `api`, `lib`, `public` ו־`scripts`.
2. ב־Vercel בוחרים **Add New → Project**, מייבאים את המאגר ובוחרים את הענף שאליו עלה הקוד.
3. משאירים **Root Directory** ריק / `.`. בוחרים **Framework Preset: Other**. ההגדרות שבקובץ `vercel.json` מגדירות `npm run build` ותיקיית פלט `public`.
4. לחיפוש YouTube מוסיפים ב־**Environment Variables** משתנה בשם `YOUTUBE_API_KEY` עם מפתח של פרויקט שבו הופעל **YouTube Data API v3**. הקטלוג והקבצים האישיים אינם דורשים את המפתח הזה.
5. לוחצים **Deploy**. אחרי הפריסה פותחים את האתר ולוחצים **בדיקת חיבור**.
6. אם מוסיפים או משנים משתנה אחרי פריסה, מבצעים **Redeploy** כדי להחיל אותו.

אין להגדיר את תיקיית `public` בתור Root Directory: שרת ה־API והתצורה נמצאים בשורש הפרויקט.

### משתנים

| שם | חובה | מטרה |
| --- | --- | --- |
| `YOUTUBE_API_KEY` | לא | חיפוש סרטונים דרך YouTube Data API v3. המפתח נשאר בשרת. |
| `APP_ACCESS_TOKEN` | לא | קוד משותף להגנת נתיבי ה־API. מזינים אותו בחלון החיבורים. אינו מערכת חשבונות ואינו מגן על קובצי הממשק הציבוריים. |
| `PORT` | לא | פורט הפיתוח המקומי; ברירת המחדל 4173. |

אפשר להזין מפתח YouTube אישי בחלון החיבורים במקום להגדיר מפתח שרת. מפתח אישי וקוד גישה נשמרים **בזיכרון הלשונית בלבד** ונשלחים לשרת האתר בבקשות המתאימות. הם אינם נשמרים בגיבוי, בקוד או בכתובות חיפוש.

### יצירת מפתח YouTube

1. פותחים פרויקט ב־[Google Cloud Console](https://console.cloud.google.com/).
2. ב־APIs & Services מפעילים **YouTube Data API v3**.
3. ב־Credentials יוצרים API Key ומגבילים אותו ל־YouTube Data API v3.
4. מוסיפים את המפתח ל־Vercel או לחלון החיבורים באתר.
5. לוחצים **בדיקת חיבור**. הבדיקה מבצעת בקשת `videos.list` אמיתית; היא אינה מבצעת חיפוש כדי לבדוק מפתח.

בקשות החיפוש יוצאות מהשרת. הגבלת מפתח לפי HTTP Referrer של דפדפן עלולה לחסום אותן; יש לבחור הגבלות שמתאימות לשימוש בשרת. מגבלות מכסה והזמינות נקבעות בחשבון Google.

## מה עובד, ומה נדרש לכל מקור

| מקור | חיפוש בתוך האתר | ניגון בתוך האתר | חיבור נדרש |
| --- | --- | --- | --- |
| קטלוג iTunes | כן | קטע היכרות, לצד קישור לשיר המלא בחנות | אינטרנט, ללא מפתח |
| YouTube | כן | נגן הווידאו הרשמי, כאשר ההטמעה מותרת | אינטרנט; מפתח נדרש לחיפוש בלבד |
| קישור YouTube אישי | הוספת קישור בודד | הנגן הרשמי, כאשר ההטמעה מותרת | אינטרנט, ללא מפתח חיפוש |
| קבצים מהמכשיר | סינון בספרייה האישית | שמע / וידאו מקומיים בפורמטים שהדפדפן תומך בהם | ללא אינטרנט לאחר שמירת הקובץ בדפדפן |
| TikTok | פתיחת חיפוש באתר TikTok | באתר TikTok | אינטרנט וזמינות האתר |
| קופיקו | פתיחת האתר החיצוני | לפי אפשרויות האתר | אינטרנט וזמינות האתר |

קטעי iTunes נועדו להיכרות עם הפריט ולקישור לחנות. הקוד אינו מוריד או שומר קטעים, אינו מכניס אותם לתור ואינו מפעיל בהם חזרה או ניגון אוטומטי. אין כאן מנגנון להורדת סרטונים או לעקיפת חסימות.

## שימוש קצר

- מחפשים אמן או שיר, ובוחרים קטלוג מוזיקה או YouTube.
- לוחצים על התמונה כדי לנגן. הלב מוסיף לאהובים, ו״שמירה״ מוסיפה לספרייה.
- בתפריט שלוש הנקודות אפשר להוסיף לפלייליסט, לתור או ל״נגן הבא״, לעקוב אחרי אמן, להעתיק קישור ולהסתיר תוכן.
- בלשונית **פלייליסטים** יוצרים אוסף. בתוך האוסף אפשר לשנות שם, לשנות סדר פריטים דרך התפריט ולייצא M3U8.
- להוספת קבצים לוחצים **קבצים מהמכשיר** או גוררים אותם לחלון. עד 200 קבצים בהוספה ועד 300MB לקובץ, בכפוף למקום הפנוי בדפדפן.
- גיבוי מלא של **המידע וההעדפות** נמצא בהגדרות. הגיבוי אינו כולל את קובצי המדיה עצמם.

רשימת התכונות המלאה: [docs/FEATURES.he.md](docs/FEATURES.he.md).

## נתונים ופרטיות

הפלייליסטים, השמורים וההעדפות נשמרים ב־localStorage. קבצים אישיים נשמרים ב־IndexedDB בדפדפן ואינם מועלים לשרת. אין מערכת חשבונות, סנכרון בין מכשירים או מסד נתונים בענן. מחיקת נתוני האתר או הסרת אחסון הדפדפן עשויות למחוק את הספרייה המקומית.

גיבוי JSON אינו כולל מפתחות או קובצי שמע. ייבוא הגיבוי ממזג אותו עם הספרייה הקיימת. כדי להשמיע פריטים מקומיים במכשיר אחר צריך להוסיף גם את הקבצים המקוריים. לאחר מעבר לדומיין אחר, כגון מכתובת Preview לכתובת Production, הדפדפן יוצר אחסון נפרד; אפשר להעביר את המידע בגיבוי ולהוסיף מחדש את הקבצים.

בעת חיפוש, מילות החיפוש נשלחות לשרת האתר ולספק שנבחר. עטיפות, קטעי היכרות ונגני וידאו נטענים מהספקים הרשמיים. ה־Service Worker שומר את מעטפת הממשק בלבד, ללא תשובות API או מדיה חיצונית.

## הפעלה מקומית ב־Windows

נדרשת Node.js 24. פותחים PowerShell בתיקיית הפרויקט:

```powershell
npm start
```

פותחים `http://localhost:4173`. אין חבילות runtime להתקנה. להגדרות מקומיות מעתיקים את `.env.example` ל־`.env` וממלאים רק את המשתנים הדרושים. אין להעלות `.env` למאגר.

אין לפתוח את `index.html` בלחיצה כפולה: פעולות ה־API, מודולי JavaScript וה־PWA צריכים שרת HTTP. הפריסה ל־Vercel אינה דורשת התקנת Node במחשב האישי.

## בדיקות

```powershell
npm test
npm run check
```

- 21 בדיקות אוטומטיות לנתונים, ייבוא/ייצוא, מיזוג גיבוי, תור, כתובות YouTube ונתיבי API.
- מקרי חיבור, מפתח שנדחה, מכסה שנגמרה ונתוני ספק נבדקים בעזרת תשובות מדומות מוגדרות. הבדיקות האוטומטיות אינן צריכות מפתח או אינטרנט.
- בוצעה גם בקשת קטלוג חיה שהחזירה 20 פריטים עם עטיפות וכתובות קטעי היכרות.
- בדיקת הדפדפן המלאה הופסקה בגלל תקלה בכלי הדפדפן. ניגון מדיה, ייבוא קבצים בדפדפן, התקנת PWA ופריסה בפועל ב־Vercel עדיין דורשים בדיקה ידנית. חיפוש YouTube חי לא נבדק ללא מפתח משתמש.

ב־[docs/TESTING.he.md](docs/TESTING.he.md) יש תרחישי קבלה קצרים להשלמת הבדיקה אחרי הפריסה.

## מבנה הפרויקט

```text
api/index.js             נתיב שרת משותף ל־Vercel
lib/providers.js         חיפוש, בדיקת חיבור, אימות והגבלת בקשות
public/index.html        ממשק עברית RTL
public/style.css         העיצוב הכהה המקורי, בהתאמה למחשב ולנייד
public/app.js            חיפוש, נגן ופעולות הממשק
public/core.js           נתונים, סינון, גיבוי ופלייליסטים
public/storage.js        localStorage ו־IndexedDB
public/sw.js             מעטפת ממשק לשימוש ללא חיבור
scripts/dev.mjs          שרת מקומי שמשתמש באותו קוד API
test/                   בדיקות Node.js
vercel.json             הגדרות פריסה וכותרות אבטחה
```

הגבלת הבקשות בקוד היא לכל מופע שרת חם; היא אינה מכסה גלובלית מבוזרת. אם משתמשים במפתח שרת באתר ציבורי, אפשר להגדיר הגבלות נוספות ב־Vercel ובחשבון Google בהתאם לצורך.
